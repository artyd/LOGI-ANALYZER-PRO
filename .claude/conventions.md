# LOGI-ANALYZER PRO — інженерні конвенції (обвʼязка Claude Code)

Аналіз збірних вантажів фарм/хім-продукції **Китай/Індія → ЄС (транзит) → Україна (імпорт)**.
Стек: Next.js App Router (16) + TypeScript, детермінований рушій + Python-скрипти, Neon Postgres (Drizzle), Vercel. UI українською, тема Control Room (акцент `#2cb878`).

## Доктрина точності (НЕ порушувати)

1. **Precision-first: краще `null`, ніж неправильне значення.** Ніколи не проставляй авторитетний код/ставку/клас, у якому не впевнений. Мовчання + `needsReview` завжди краще за здогад.
2. **Не вигадувати дані.** Коди УКТЗЕД, ставки мита, норми — лише з реальних джерел. Немає джерела → `null` + попередження. Особливо: **НЕ фабрикувати тарифні ставки** (див. `lib/engines/statutory.ts` — файл порожній навмисно, бо bulk-даних 2697-IX у відкритому доступі немає).
3. **Реальні коди.** Будь-який код валідується проти справжньої номенклатури HS (`lib/data/hs_valid6.json`, `lib/engines/validate.ts`). Вигаданих кодів не додавати навіть у синоніми (`lib/data/uktzed_code_db_extra.ts`).
4. **Межа детермінізм / AI.** Гроші (мито, ПДВ, митна вартість) рахує ЛИШЕ детермінований рушій (`lib/engines/payment.ts`). AI повертає лише описові/класифікаційні поля й спирається виключно на CONTEXT (тариф-факти + RAG-рулбук), не на пам'ять — `lib/ai/prompt.ts`.
5. **Джерело істини несе кожне число:** `{ value, estimated, source }`; `source` ∈ `user | db | kb_coarse | ai | fallback | unknown`. `db` = авторитетно, решта = оцінка (`estimated=true`, тягне `needsReview`).
6. **Хімічна безпека матчингу.** Різниця в 1 символ у хім-назві часто = ІНША речовина (`sulfate≠sulfite`, `cystine≠cysteine`). Fuzzy — лише ПІДКАЗКА людині, ніколи не тиха автозаміна (`lib/engines/match.ts`).

## Пріоритет джерел (у `lib/engines/resolve.ts`)

- **Код:** явний код користувача → курований словник (`uktzed_code_db*`) → семантичний HS-fallback за описом (`hsmatch.ts`, лише за токеном-ідентичністю) → пропозиція AI (валідована) → `null`.
- **Ставка мита:** тариф користувача (runtime) → статутний 10-знак (`statutory.ts`, поки порожній) → реальна MFN WITS HS-6 (`mfn.ts`) → груба таблиця.
- Код-пропозиція (HS-опис/AI) ⇒ ставка від нього завжди `estimated`, навіть якщо MFN однорідна.

## Вимірюваність — golden harness

- **Кожна зміна рушія міряється числами:** `npm run test:golden` (звіт точності по полях). Див. `/accuracy`.
- `tests/golden/cases.json` — істина, **звірена ЛЮДИНОЮ** (реальні рядки маніфестів + правильна відповідь), НЕ вивід рушія. Розширювати реальними позиціями. Див. `/add-golden`.
- Гейт перед комітом: `/check` (tsc + усі тести + `next build`).

## Стиль

- **Коментарі в коді — українською** (як у наявному коді). Іменування/ідіоми — під сусідній код.
- **Next.js:** перед кодом читати `node_modules/next/dist/docs/` — версія з breaking changes (див. `AGENTS.md`).
- Тимчасові файли — у scratchpad, не в репо. Прибирати артефакти тестів (`doc_out/`, `_probe.*`, `scratch_*`).

## Карта рушія

- `resolve.ts` — оркестратор грунтування позиції (код/ставка/походження/ADR/прекурсори).
- `match.ts` — токен-матчер + fuzzy-підказка. `classify.ts` — лукапи довідників. `hsmatch.ts` — HS-fallback (IDF).
- `payment.ts` — розрахунок платежів. `mfn.ts`/`statutory.ts` — ставки. `validate.ts` — валідація коду.
- `lib/ai/` — `prompt.ts` (грунтований системний), `rag.ts` (теми рулбуку в CONTEXT), `providers.ts` (BYOK-проксі), `schema.ts`.
- `lib/tariff/tariff.ts` — runtime-інгест тарифу користувача. `scripts/doc_extract.py` — документи → чистий текст + ідентифікатори.

## Реалії середовища

Windows/PowerShell + Git Bash; Node 20, Python 3.14 (fitz/docx/openpyxl/PIL є, tesseract НЕМА). `\b` у regex НЕ працює з кирилицею — не використовувати для кириличних патернів.
