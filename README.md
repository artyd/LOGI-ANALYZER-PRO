# LOGI-ANALYZER PRO

Аналіз збірних вантажів (фарм/хім) на транзит через ЄС та імпорт в Україну:
розрахунок митних платежів, коди УКТЗЕД, походження, комплаєнс-перевірки.
Next.js 16 (App Router, TypeScript) + детерміновані рушії розрахунку.

## Розгортання на Vercel

Застосунок лежить у **корені** репозиторію — Vercel визначає Next.js автоматично,
жодних додаткових налаштувань не потрібно (**Root Directory** лишити порожнім / `.`).

Змінні оточення — див. `.env.example` (`DATABASE_URL` — Neon Postgres, коли буде готовий).

## Локальна розробка

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # юніт-тести рушіїв (Vitest) — 42 проходять
npm run build      # продакшн-білд
```

## Структура

| Шлях | Що це |
|------|-------|
| `app/` | Next.js App Router (сторінки + `api/ai` — BYOK-проксі до AI) |
| `lib/engines/` | Розрахунок платежів, класифікація, резолвер (чисті, тестовані) |
| `lib/data/` | Довідники, мігровані зі старої версії (origin/УКТЗЕД/ADR/прекурсори/пошлини) |
| `lib/db/` | Схема Neon/Drizzle |
| `lib/ai/` | Грунтований промпт + провайдери |
| `scripts/` | Екстрактор довідників, сид БД |
| `tests/` | Vitest |

Прогрес і наступні кроки — `PROGRESS.md`. Legacy-версія (single-file `index.html`)
доступна в історії git (коміт `3a4d726`).
